  for i in range(0,5):

    age=input("Enter age")

  Can be refactored to:

  ```python
def getUserData():
    users = [{"name": input("Enter name"), "age": input("Enter age")} for _ in range(5)]
    return users
  ```

  >> total = 0
  for i in range(len(data)):
    total += int(data[i]["age"])
  avg = total/len(data)

  Can be simplified using list comprehension and built-in functions:

  ```python
def process():
    data = getUserData()
    avg = sum(int(user["age"]) for user in data) / len(data)
    print("old users" if avg > 50 else "young users")
  ```
